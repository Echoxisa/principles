# 原则 · 身份

极简本地原则本：记录你**仍选择**的身份原则，以及**不再选择**的轨迹。

想法 · 语言 · 行动 —— 用生活反馈迭代，而不是堆积材料。

## 功能

- **生效中**：当前身份原则（增删改）
- **已不选择**：归档并可选填写原因（不选择也是一种选择）
- **生活反馈**：为原则记想法 / 语言 / 行动
- **导出 / 导入 JSON**：本机备份与迁移

数据默认存在**你打开网站的那台浏览器**的 `localStorage` 里（不经过服务器）。换设备或清缓存会丢数据，请用页面上的「导出」备份。
